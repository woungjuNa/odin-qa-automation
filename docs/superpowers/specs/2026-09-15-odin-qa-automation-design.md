# 오딘: 발할라 라이징 QA 자동화 - 스모크 테스트 (Phase 1) 설계

## 목적

게임 QA 이직 포트폴리오용 프로젝트. 실제 MMORPG QA 경력(PC/AOS/iOS 동시 서비스 모바일 MMORPG)과
연결되는, 화면 인식 기반 게임 자동화 시스템을 구축한다.

Phase 1의 범위는 **스모크 테스트**로 한정한다: 게임 실행 → 로그인 → 메인 화면 진입까지
정상 동작하는지 자동으로 검증하고, 결과를 리포트로 남긴다.

## 배경 / 제약

- 대상 게임: 오딘: 발할라 라이징 (언리퀄 엔진 기반, 카카오게임즈 PC 클라이언트)
- 안드로이드 단말기 보유하지 않음 → PC 클라이언트로 테스트 (에뮬레이터/단말 불필요)
- 게임 화면은 렌더링된 그래픽이라 일반 Windows UI 자동화(pywinauto 등)로 요소를 인식할 수 없음
  → 이미지 인식 기반 자동화가 필요
- 담당자 코딩 경험: 약 3년 전, 프론트엔드(HTML/CSS) 위주. 로직 중심 프로그래밍 경험은 적음
- 코딩 관련 개발 환경(Python, 에디터 등) 미설치 상태 → 처음부터 설치 안내 필요

## 접근 방식

**Airtest** (넷이즈의 게임 QA 자동화 오픈소스 프레임워크)를 사용한다.

이유:
- 이미지 매칭 기반 자동화를 직접 구현(OpenCV+PyAutoGUI)하는 것보다 학습 곡선이 낮아,
  코딩 공백이 있는 상태에서도 완주 가능성이 높음
- 실제 게임업계 QA 자동화 현장에서 쓰이는 툴이라 "실무 툴 활용 경험"으로 포트폴리오에 어필 가능
- 실행 결과를 HTML 리포트(단계별 스크린샷 포함)로 자동 생성 → 별도 리포팅 기능 구현 불필요

## 전체 흐름

1. 오딘 PC 클라이언트 실행 상태에서 시작
2. 인트로/스플래시 화면 통과 (로고/버튼 이미지 매칭 후 클릭)
3. 로그인 처리 (계정 정보 입력 또는 자동로그인 상태 확인)
4. 메인 화면 진입 대기 → 메인 화면 특정 UI 요소(메뉴 아이콘 등) 인식 성공 시 "로그인 성공"으로 판정
5. 결과 기록 및 Airtest 리포트 생성

## 구성 요소 및 파일 구조

```
QA_AI/
├── templates/              # 화면 인식용 기준 이미지 (버튼, 로고 등 스크린샷)
│   ├── splash_logo.png
│   ├── login_button.png
│   └── main_menu_icon.png
├── scripts/
│   └── smoke_test.py       # 메인 테스트 스크립트 (Airtest 기반)
├── reports/                 # Airtest 자동 생성 리포트 저장 위치
├── config.py                 # 계정 정보 등 민감 정보 (.gitignore로 git 제외)
├── .gitignore
└── README.md                 # 프로젝트 설명 (포트폴리오 핵심 문서)
```

- **templates/**: 인식할 버튼·화면 요소를 미리 캡처해서 저장. 매칭 대상이 늘어나면 여기에 추가
- **scripts/smoke_test.py**: Airtest의 `touch()`, `wait()`, `exists()` 등으로 전체 흐름을 구현
- **config.py**: 계정 ID/PW를 코드에 하드코딩하지 않고 분리, `.gitignore`에 추가
  (깃허브에 올릴 때 보안 실수 방지 — 실무 QA 관점에서도 좋은 습관으로 포트폴리오에 언급 가능)

## 에러 처리 & 리포트

- 각 단계마다 타임아웃 설정 (예: 10초 내 해당 화면 요소를 못 찾으면 실패 처리)
- 실패 시점 스크린샷 자동 저장
- 각 단계 진행 상황을 로그로 남김 (예: "로그인 버튼 클릭 시도")
- Airtest가 HTML 리포트를 자동 생성 (단계별 스크린샷 + 성공/실패 로그 포함)

## 향후 확장 (Phase 1 범위 밖)

- 반복 작업 검증 (일일퀘스트, 사냥터 이동, 자동전투 등 시나리오 후 상태 체크)
- UI 회귀 테스트 (이미지 비교 기반)
- 특정 버그 재현 자동화
- 플랫폼 확장: 니케 등 다른 게임, 또는 iOS/Android
- 심화: Airtest 대신 OpenCV/PyAutoGUI로 직접 구현해보며 기술 이해도 심화

## 테스트 방법 (자동화 스크립트 자체의 검증)

- 템플릿 이미지가 실제 게임 화면과 정확히 매칭되는지 수동으로 1차 확인
- 여러 번 반복 실행하여 화면 밝기/그래픽 설정 차이로 인한 오탐(false positive/negative) 여부 점검
